# HR Analysis Dashboard

## 📌 Project Overview
This HR Analysis project aims to analyze employee data and provide insights that support data-driven decision making in HR activities such as recruitment, performance, employee retention, and workforce planning. The dashboard helps HR teams understand key workforce metrics, identify trends, and improve organizational efficiency.

---

## ✅ Objectives
- Analyze employee demographics (age, gender, department, education, etc.)
- Measure employee performance, attendance, and experience
- Track hiring, attrition, and retention metrics
- Identify departments with high attrition or low performance
- Provide data-driven insights to support HR decision-making

---

## ✅ Tools & Technologies
- **Power BI**
- Excel / CSV dataset
- Data cleaning & transformation in Power Query
- DAX measures for KPIs

---

## ✅ Key Features of Dashboard
- Total Employees, Attrition Rate, Average Salary & Job Satisfaction Score
- Department-wise employee count and attrition
- Hiring trend over time
- Employee experience vs salary
- Age and gender distribution
- Performance rating analysis
- Education level breakdown

---

## ✅ Insights Derived
- Which department has highest attrition?
- Which age group shows maximum turnover?
- Which job role has the highest salary gap?
- Trend of recruitment and attrition over months/years
- Relationship between experience and salary

## ✅ How to Use the Dashboard
1. Import dataset into Power BI
2. Apply data cleaning in Power Query
3. Use DAX to create KPIs and calculated columns
4. Create visuals like bar chart, pie chart, map, stacked column, donut chart
5. Interact with slicers for department, gender, or experience
